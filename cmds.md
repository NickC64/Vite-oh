# Bot Command and Controls

- `/proposal` — Privately opens the web workspace for the current server.

The five-minute launch link is random and single-use. Opening it creates a
secure seven-day browser session; it does not require a second Discord login.
Run `/proposal` in another server to add that server to the same workspace.

Active proposal messages provide **Veto**, **Acknowledge**, **Subscribe**,
**Nudge**, and **Open workspace**. Nudge opens a private Discord member picker.
Terminal proposals retain **Open workspace**.
